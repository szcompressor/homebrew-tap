# szcompressor Homebrew tap

Homebrew formulae for [SZ3](https://github.com/szcompressor/SZ3), an error-bounded lossy compressor for scientific data.

## Install

```bash
brew install szcompressor/tap/sz3
```

Or `brew tap szcompressor/tap` once, then `brew install sz3`. `brew upgrade` updates it like any other formula.

The `sz3` formula installs the `sz3` command-line tool, `libSZ3c` (C API) and the C++ headers with their CMake
package (`find_package(SZ3)`).
